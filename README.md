# ResultsPack
Version **1.0.1** is the first minor fix to the first public release.

ResultsPack is an independent module for [IANSEO](https://www.ianseo.net/) that allows Tournament Organisers to build a complete results sheet, complying with the requirements of ArcheryGB Record Status.

ResultsPack creates one continuously paginated PDF, containing any selected combination of:

- statutory results-sheet cover page;
- individual qualification results;
- team qualification results;
- (h2h) individual and team final rankings and h2h brackets;
- custom awards that cannot be generated by calculation (for instance, "Best Gold").

Results Pack 1.0.1 is written to work with the IANSEO **2026-03-01** release. Because the module integrates with IANSEO, future changes to IANSEO may require compatibility updates.

## Installing ResultsPack

**Option 1:** Go to the Releases section of this repository and download the
`ResultsPack-x.x.x.zip` file listed under Assets.

Extract the downloaded ZIP. It contains a folder named "ResultsPack".

Copy that entire folder into:

```text
    ianseo/htdocs/Modules/Custom/
```

The final path should therefore be:

```text
    ianseo/htdocs/Modules/Custom/ResultsPack/
```

Then open IANSEO and go to:

```text
    Results Pack → Build results sheet
```

**Option 2:** Download the archive and extract the ZIP. 

Navigate to:
```text
ianseo/htdocs/Modules/Custom/
```
And create a folder inside called "ResultsPack".

Copy the contents of the extracted zip to:

```text
ianseo/htdocs/Modules/Custom/ResultsPack/
```

BEWARE github will create a folder called "ResultsPack-main" which will break the menu structure. The folder must be called "ResultsPack" only.

Then open IANSEO. Identify the new menu item and go:

```text
Results Pack → Build results sheet
```

Results Pack creates its own settings and custom-award tables automatically when first needed.

## Removing ResultsPack

ResultsPack does not alter IANSEO scoring tables. It creates and writes only to:

```text
CustomResultsPackSettings
CustomResultsPackAwards
```

Before removing a module, please remember to back up your competitions. Deleting the ResultsPack folder removes the ResultsPack module and should not affect competition data. The two module tables may be dropped afterwards if saved ResultsPack settings and award definitions are no longer required.

## Development

ResultsPack is developed and maintained by Philip Taylor. Bug reports and other gripes are very welcome.

- I am working on allowing the tool to combine results across multiple events. This is currently in prototype and does not work consistently or correctly. For now, please just select one competition.
- Indoor detection is not yet reliable, please let me know if you spot an incorrectly detected round.
- IANSEO PDF generator/other dependencies may change between IANSEO releases. This tool is liable to break if that happens.
